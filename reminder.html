DAILY REMINDER

膝コゾ

毎日 21:00 日本時間

アプリを閉じていても受信できるプッシュ通知です。GitHub Actionsから送ります。

STEP 1 / スマホの通知登録

この端末で通知を許可

このアプリを入れたAndroidスマホで押してください。通知の許可画面が表示されます。

未設定

STEP 2 / GitHubの設定

通知登録情報をコピー

作成後にコピーし、GitHubリポジトリの Settings → Secrets and variables → Actions → New repository secret に登録します。

Secret namePUSH_CONFIG

コピーした情報には秘密鍵が含まれます。GitHubの通常ファイル、README、Issue、公開チャットには貼らず、必ずRepository secretに保存してください。

STEP 3 / 届くか確認

通知をテストする

このボタンは端末での通知表示だけを確認します。実際の配信確認はGitHubの「Actions → 膝コゾ・21時通知 → Run workflow」で行ってください。

設定をやり直す場合

「通知登録を作成」を再度押すと、既存の登録情報はそのまま再表示します。端末変更・登録エラーがある場合は登録を解除してから作り直し、GitHubのSecretも上書きしてください。

GitHub Actionsは21時ちょうどの実行を保証しません。Publicリポジトリは約60日間更新がないと定期実行が自動停止することがあります。
