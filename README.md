# デュアルストップウォッチ (PWA)

スマートフォン画面の上半分・下半分が独立したストップウォッチです。

- 上半分タップ：ストップウォッチ①の開始／停止／再開
- 下半分タップ：ストップウォッチ②の開始／停止／再開
- 中央の「両方リセット」：確認画面を表示してから両方の時間をゼロに戻す
- 時間は `時:分:秒.百分の一秒` 表示。24時間超でも時間は繰り上がる
- 2つとも動作中は同時に計測する
- 操作状態は端末内に保存され、アプリを閉じても次回開いたときに継続（計測中は閉じている間の経過時間も含む）
- 初回オンライン起動・キャッシュ保存後はオフラインで利用可能
- 外部通信・広告・アクセス解析なし（初回は自分で置いたサイトのファイルのみ読み込み）

## PWAとしてインストールする

1. このフォルダ内のファイルと `icons` フォルダを **構成を変えずに** HTTPS 対応の静的サイトへアップロードする。GitHub Pages / Cloudflare Pages / Netlify 等で動きます。
2. Android の Chrome でそのサイトの URL を開く。
3. ブラウザメニューの「ホーム画面に追加」または「アプリをインストール」からインストールする（ブラウザ・端末の表示により異なります）。
4. 一度オンラインで読み込みを完了すると、その後はオフラインでも利用できます。

**注意：** `index.html` を `file://` で直接開いても通常のタイマーとしては動く場合がありますが、PWA のオフライン機能とインストールは使えません。PWAには HTTPS または localhost が必要です。

## Windows 11 でローカル動作確認

Python が入っている場合、PowerShell で展開したフォルダへ移動して実行：

```powershell
py -m http.server 8000
```

PCのブラウザで `http://localhost:8000/` を開いて動作確認できます。停止するには PowerShell で Ctrl+C。

## 構成

- `index.html` : 画面・確認ダイアログ
- `styles.css` : スマホに合わせたデザイン
- `app.js` : 独立した計測ロジック・保存・PWA登録
- `manifest.webmanifest` : アプリ名称・アイコン・インストール設定
- `sw.js` : オフライン読み込み用 Service Worker
- `icons/` : アプリアイコン

## 計測仕様

100分の1秒表示は端末の時計に基づくもので、競技用の高精度計時器ではありません。端末のシステム日時を計測中に大きく変更すると、経過時間がずれる場合があります。ブラウザデータを削除すると計測状態も消えます。
